# FlyHigh Landing Page

This is a simple landing page built with Webpack.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

## Development

To start the development server:
```
npm start
```
This will open your browser to `http://localhost:9000`.

## Build

To build for production:
```
npm run build
```
The built files will be in the `dist/` directory.
